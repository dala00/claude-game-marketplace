# 巡回——三つの部屋を探す

## ナレーション

壁が溶け、三つの扉が並ぶ。
左から——第一の部屋、第二の部屋、第三の部屋。
どの扉も、今度は手で押せば開く。

最後の鍵は、どこかにある。
頼りない光の、その真下に。

---

## 探索の判定（AI 用 — 重要）

プレイヤーが指定する「部屋」と「探す場所」の組み合わせで判定する:

### 正解（最後の鍵を発見）

- **第一の部屋に行き**、「中央の床」「テーブルがあった場所の床」「光の真下の床」「頼りない光の下」等を調べる行動
  - さらに「テーブルを動かす」「床に手を当てる」「床を叩く」等で具体的に探る
  - → 「テーブルを動かすと、その下の床板の一枚に、わずかな段差がある」等の描写
- 続けて「床板を持ち上げる」「板を剥がす」「段差を引く」等 → `story/final_key_found.md` を Read して提示

**短縮判定**: 第一の部屋に戻り「光の真下を掘る／剥がす／持ち上げる」等の意図が明確な行動 → `story/final_key_found.md` 直行で構わない

### 不正解（その場所には何もない）

- 第二の部屋を調べる → 「絵画はもう外したまま、壁に立てかけられている。裏にも、何もない。床にも、特に変わった様子はない」等
- 第三の部屋を調べる → 「振り子時計は静止したまま。扉も開かれたまま。床も壁も、何も語らない」等
- 第一の部屋でテーブル以外を調べる → 「テーブル以外には、ここにも何も変わったものはない」等
- その他、ヒントから外れた場所 → 「光の届かぬ場所には、何もない」等

### 共通

- どの場合も、不正解では**遷移しない**。プレイヤーの次の入力を待つ
- 「動けない」「もう疲れた」等の停滞 → 「ここを出るには、鍵を見つけるしかない」と促す
- ヒント要求 → 「最初に目を覚ました場所」「光の真下」を控えめに再掲。具体的な「テーブルを動かす」までは言わない

## 注意（AI 厳守）

- 最後の鍵の隠し場所: **第一の部屋（room 1）の、中央天井の頼りない光の真下、テーブルが置かれていた直下の床板の下**。
- これ以外の場所からは絶対に鍵を出さない。捏造しない。
- 探索が長引いてもプレイヤーが諦めるまで遷移しない。ヒントを段階的に明確にしてもよいが、答えそのものは一度に明かさない。
