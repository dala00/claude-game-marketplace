# 第一幕（2）— 夕食の席

## ナレーション（そのまま提示する）

夕食の席は、大広間に設けられた。

上座に座る体の大きな男が、今日着いた客——高坂宗市（たかさか そういち）。リゾート開発会社の社長だ。よく通る声で、座を自分のものにしている。
その隣で、しきりに愛想笑いを浮かべているのが、秘書の真壁亮（まかべ りょう）。
少し離れた席では、和服を着崩した男がひとり、手酌で酒を飲んでいる。烏丸京介（からすま きょうすけ）——作家で、この宿の常連らしい。

料理を運ぶのは、トキと小夜、それに料理人の佐伯千鶴（さえき ちづる）。物静かな女性で、目を伏せたまま、膳を置く手つきだけが正確だ。
廊下の端には源爺が控え、「道が、閉まりましたわい」と誰にともなく告げた。雪で道路が封鎖されたのだ。

酒が回った頃、高坂が箸を置いて言った。
「単刀直入に言おう。この宿は更地にする。跡には十二階建てのリゾートホテルが建つ。ランプ？ ——ガラクタはまとめて処分だ」

トキが、背筋を伸ばしたまま静かに返す。「灯りは、この宿の魂でございます」
「魂で借金は返せんよ、女将」
烏丸が杯越しにつぶやいた。「あんたの建てる物はどれも墓石みたいだがね」
真壁が慌てて場を取りなす。酌に回っていた千鶴の手が、徳利を持ったまま、ほんの一瞬だけ止まった——気のせいかもしれない、その程度の間だった。

高坂はふところから葉巻を出し、立ち上がった。
「わしは離れで契約書を仕上げる。**朝まで誰も寄越すな**。朝食は七時半に運ばせろ」

雪は、まだ降り続いている。

## シーン内の自由行動（遷移なし — この範囲で応答する）

- **高坂と話す** → 横柄。「あんたが修復屋か。査定書だけはちゃんと書けよ。売値に響く」程度で取り合わない
- **トキと話す** → 丁寧に詫びる。「お見苦しいところを。……灯りのために宿を売る。笑い話にもなりませんでしょう」
- **小夜と話す** → 心配そうに声をひそめる。「……あの人、本気で宿を壊す気なんでしょうか」
- **千鶴と話す** → 物静かな料理人。手を止めず、丁寧な敬語で短く受け答えする
- **烏丸と話す** → 皮肉屋。「高坂とは古い馴染みでね。向こうは儂（わし）の顔など見たくもなかろうが」と笑う
- **真壁と話す** → 神経質な愛想笑い。「社長はああいう方ですが、悪気は……いえ、あるんでしょうな」
- **源爺と話す** → 口数少なく。「この降りは、ようけ積もりますわい」
- **ランプ・大広間を観察する** → ランプの宿らしい描写を自由に
- **高坂についていく・離れに行く** → 「ついてくるな」と一蹴される。源爺も「離れへの渡りは雪がひどうございます」と止める
