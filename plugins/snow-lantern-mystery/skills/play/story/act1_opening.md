# 第一幕 開幕 — 燈の夕餉

## ナレーション（そのまま提示する）

雪は、三日前から降り続いている。

信州の山あい、灯守（ひもり）の宿。明治の頃から続くこの湯宿は、「ランプの宿」の名で知られている。廊下の角に、座敷の床の間に、湯殿への渡りに——百を超える骨董の灯火器が、今も毎夜、本物の火を揺らしている。

霧島律（きりしま りつ）。それが、この物語の主人公——プレイヤーの名だ。
古美術修復師。灯火器の修復を専門とする。
この宿のコレクションの査定と修復を頼まれ、三日前から逗留している。依頼主は女将の灯守トキ。宿の経営は傾き、コレクションごと宿を手放す話が出ているのだという。

その「買い手」が、今日の昼、到着した。

夕餉の席は大広間に設けられた。
上座に陣取る恰幅のいい男が、高坂宗市。リゾート開発会社の社長だ。その隣で揉み手をしているのが秘書の真壁亮。離れた席で杯を舐めている着流しの男は烏丸京介——作家で、この宿の常連らしい。
膳を運ぶのは、女将のトキ、孫娘の小夜、それに料理人の佐伯千鶴。廊下の端には下足番の源爺が控え、「道が、閉まりましたわい」と誰にともなく告げた。雪で道路が封鎖されたのだ。

酒が回った頃、高坂が箸を置いて言った。
「単刀直入に言おう。この宿は更地にする。跡には十二階建てのリゾートホテルが建つ。ランプ？ ——ガラクタはまとめて処分だ」

女将のトキが、背筋を伸ばしたまま静かに返す。「灯りは、この宿の魂でございます」
「魂で借金は返せんよ、女将」
烏丸が杯越しに呟いた。「あんたの建てる物はどれも墓石みたいだがね」
真壁が慌てて場を取りなす。酌に回っていた千鶴の手が、徳利を持ったまま、ほんの一瞬だけ止まった——気のせいかもしれない、その程度の間だった。

高坂は懐から葉巻を出し、立ち上がった。
「わしは離れで契約書を仕上げる。**朝まで誰も寄越すな**。朝餉は七時半に運ばせろ」

雪は、まだ降り続いている。

## シーン内の自由行動（遷移なし — この範囲で応答する）

- **高坂と話す** → 横柄。「あんたが修復屋か。査定書だけはちゃんと書けよ。売値に響く」程度で取り合わない
- **トキと話す** → 丁寧に詫びる。「お見苦しいところを。……灯りのために宿を売る。笑い話にもなりませんでしょう」
- **小夜と話す** → 十九歳、帳場手伝い。ランプの話になると目が輝く。「先生、三番の棚のオイルランプ、あれが一番好きなんです」
- **千鶴と話す** → 物静かな料理人。手を止めず、丁寧な敬語で短く受け答えする
- **烏丸と話す** → 皮肉屋。「高坂とは古い馴染みでね。向こうは儂の顔など見たくもなかろうが」と笑う
- **真壁と話す** → 神経質な愛想笑い。「社長はああいう方ですが、悪気は……いえ、あるんでしょうな」
- **源爺と話す** → 朴訥。「この降りは、ようけ積もりますわい」
- **ランプ・宿を観察する** → ランプの宿らしい描写を自由に。査定の仕事の手応えなど
- **高坂についていく・離れに行く** → 「ついてくるな」と一蹴される。源爺も「離れへの渡りは雪がひどうございます」と止める
