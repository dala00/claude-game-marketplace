# 第一幕（2）— 結界の夕餉

## ナレーション（そのまま提示する）

日没の鐘が鳴る。

中庭で、アンセルム院長が杖を掲げると、淡い光の膜が院全体をすっぽりと包んだ。魔物除けの大結界。日没から夜明けまで、これを破らずに出入りすることは誰にもできない。開け閉てができるのは院長の杖だけで、その開け閉てはすべて、鐘塔の記録水晶に刻まれる。
「山の夜は、魔のものの刻ですからな」と、院長は笑った。

夕餉（ゆうげ）——夕食の席は、食堂に設けられた。

上座に、銀縁の片眼鏡の男。ギデオン・ファルク——王都から来た王室聖遺物鑑定官。物の本物と偽物を見極めるのが役目で、丁寧すぎるほど丁寧な物腰の端々に、刃物のような皮肉が覗く。
その斜め後ろに、若い騎士がまっすぐに立っている。セドリック、二十九歳。ファルクの護衛で、食事の席でも姿勢を崩さない。
院長の隣で揉み手をしているのは、でっぷりと太った男だ。行商人のドルフ、五十一歳。数日前から泊まり込んで、櫛だの香だの魔導具の小物だのを売っているらしい。
末席では、大柄な男が岩のように黙って匙を動かしている。バルト、四十五歳。鍛冶修道士——午後の槌の音の主で、この院で炎の魔法を使えるのは彼ひとりだという。
膳を運ぶのは、ユーリスとミレイだ。

杯が一巡りした頃、ファルクが口を開いた。
「昼に一度、検めさせてもらった。……ふむ。結論は明朝、王都へ送る。この院にとって良い報せかどうかは、まだ言えんがね」
院長の眉がかすかに動いた。ドルフが「いやあ、本物に決まっとりますよ。あの照り、あの気品」と調子を合わせ、片眼鏡でじろりと見られて黙り込んだ。

「それより——」ファルクの声が低くなる。「セドリック卿。貴様、道中の宿で誰に何を喋った? 妙に旅程の知れた顔が多い」
「……存じません」
「口の軽い護衛ほど高くつくものはない。王都に帰ったら話がある」
騎士の顎がこわばった。短い、しかし刺すような沈黙が卓に落ちた。

院長が場を和らげるように、晩課（ばんか）——夜の祈りの集まりへ鑑定官を誘った。返ってきたのは素っ気ない一言だった。
「**祈りは結構。仕事中だ、構うな。**——夕食後にもう一度だけ庫を検める。管理の方、鍵を頼みますよ」
「は、はい。お供いたします」とユーリスが頭を下げた。

膳が下げられていく。ユーリスが客人の部屋の灯りと夜着の支度に立った。宿坊係の、いつもの夜の仕事だ。ミレイは片付けに、バルトは炉の火の番に戻っていく。

窓の外で、結界の光がかすかに揺れている。
山の夜が、始まろうとしていた。

## シーン内の自由行動（遷移なし — この範囲で応答する）

- **ファルクと話す** → 丁寧だが無礼。「ほう、魔導具の修理屋。刻印読みか。……物は嘘をつかん。人と違ってね」と片眼鏡を光らせる程度で、鑑定の中身は話さない
- **セドリックと話す** → 硬い。「職務中です」とだけ。叱られた件に触れると目を伏せて黙る
- **バルトと話す** → 無骨。「……飯のときくらい、火の話はよせ」と短い。悪意はない
- **ドルフと話す** → 商売っ気たっぷり。「修理屋の旦那! 砥石は要らんかね、東方の香は」と荷を広げたがる
- **アンセルムと話す** → 穏やかな世間話。聖杯の話になると、わずかに言葉を選ぶ素振り
- **ユーリスと話す** → 給仕の合間に丁寧に応じる。「お客さまが多い夜は、支度も張り合いがあります」
- **ミレイと話す** → 「鑑定官さまのお膳、いちばん緊張します……」と小声でこぼす
- **聖杯を見たい・聖遺物庫に行く** → ユーリスが恐縮して断る。「検めの最中ですので、どうか明日に」。ファルクも「部外者は遠慮願おう」と取り合わない
