# 第一幕 開幕 — 結界の夕餉

## ナレーション（そのまま提示する）

街道が尽きて山道に変わってから、半日。谷あいに鐘塔が見えたとき、日はもう西に傾きはじめていた。

聖アルヴェル修道院。三百年前、聖者アルヴェルが魔の峰を封じたと伝わる古い院で、いまは峠を行く旅人を泊める宿坊を兼ねている。

リオン・ヴェイル。それが、この物語の主人公——プレイヤーの名だ。
遍歴の魔導具修理師。魔法は、使った者の癖を「刻印（こくいん）」として物に残す。指紋のように一人ひとり違うその紋様を読み、魔導具の狂いを直すのがヴェイルの仕事だ。この院には年に一度、灯火具と結界の楔石（くさびいし）の整備に呼ばれる。今年で三度目になる。

午後いっぱいを掛けて、客室棟の魔導ランタンを一基ずつ検めた。芯核の魔力を充たし、時限のダイヤルは——癖でそうするのだが——すべて「手動」の位置に戻して、仕事を終えた。

院は今年、妙に人が多い。
王都から聖遺物鑑定官が来ているのだという。院の至宝、聖者の遺した銀の杯『暁の聖杯』の「検め」のためだ。十年に一度あるかないかの王命——東の都の競売に、聖杯とよく似た品が出たという噂が、王都に届いたかららしい。

日没の鐘が鳴る。
院長アンセルムが杖を掲げると、淡い光の帳が院全体を包んだ。魔物除けの大結界。日没から夜明けまで、これを破らずに出入りすることは誰にもできない。開け閉てができるのは院長の杖だけで、その開閉はすべて、鐘塔の記録水晶に刻まれる。
「山の夜は、魔のものの刻ですからな」と、院長は笑った。

夕餉の席は食堂に設けられた。

上座に、銀縁の片眼鏡の男——王室聖遺物鑑定官、ギデオン・ファルク。慇懃な物腰の端々に、刃物のような皮肉が覗く。その斜め後ろに直立しているのが、護衛の騎士セドリック。
院長アンセルムの隣で、恰幅のいい男が揉み手をしている。行商人のドルフ。数日前から逗留して、櫛だの香だの魔導具の小物だのを売っているらしい。末席では、鍛冶修道士のバルトが岩のように黙って匙を動かしている。膳を運ぶのは、聖遺物管理と宿坊係を兼ねる修道士ユーリスと、見習い修道女のミレイだ。

杯が一巡りした頃、ファルクが口を開いた。
「昼に一度、検めさせてもらった。……ふむ。結論は明朝、王都へ送る。この院にとって良い報せかどうかは、まだ言えんがね」
院長の眉がかすかに動いた。ドルフが「いやあ、本物に決まっとりますよ。あの照り、あの気品」と調子を合わせ、片眼鏡の一瞥で黙らされた。

「それより——」ファルクの声が低くなる。「セドリック卿。貴様、道中の宿で誰に何を喋った? 妙に旅程の知れた顔が多い」
「……存じません」
「口の軽い護衛ほど高くつくものはない。王都に帰ったら話がある」
騎士の顎が強張った。短い、しかし刺すような沈黙が卓に落ちた。

院長が取りなすように、晩課の祈りへ鑑定官を誘った。返ってきたのは素っ気ない一言だった。
「**祈りは結構。仕事中だ、構うな。**——夕食後にもう一度だけ庫を検める。管理の方、鍵を頼みますよ」
「は、はい。お供いたします」とユーリスが頭を下げた。

膳が下げられていく。ユーリスが客人の部屋の灯りと夜着の支度に立った。宿坊係の、いつもの夜の仕事だ。ミレイは片付けに、バルトは炉の火の番に戻っていく。

窓の外で、結界の光がかすかに揺れている。
山の夜が、始まろうとしていた。

## シーン内の自由行動（遷移なし — この範囲で応答する）

- **ファルクと話す** → 慇懃無礼。「ほう、魔導具の修理屋。刻印読みか。……物は嘘をつかん。人と違ってね」と片眼鏡を光らせる程度で、鑑定の中身は話さない
- **セドリックと話す** → 硬い。「職務中です」とだけ。叱責の件に触れると目を伏せて黙る
- **アンセルムと話す** → 柔和な老人。「ヴェイル殿の手が入ると、灯りの色が良うなる」。聖杯の話になると、わずかに言葉を選ぶ素振り
- **ユーリスと話す** → 物腰の柔らかい修道士。「灯火の整備、いつも助かります。書庫の写本灯も、おかげで目に優しく」と丁寧に礼を言う
- **バルトと話す** → 無骨。「……飯のときくらい、火の話はよせ」と短い。悪意はない
- **ドルフと話す** → 商売っ気たっぷり。「修理屋の旦那! 砥石は要らんかね、東方の香は」と荷を広げたがる
- **ミレイと話す** → 十六の見習い。よく動き、よく喋る。「ヴェイルさまの直したランタン、字を写すとき全然ちらつかないんです!」
- **聖杯を見たい・聖遺物庫に行く** → ユーリスが恐縮して断る。「検めの最中ですので、どうか明日に」。ファルクも「部外者は遠慮願おう」と取り合わない
- **院や結界を観察する** → 整備で訪れた者の目線で自由に描写してよい（結界の楔石、回廊、水時計と鐘の暮らしなど）
