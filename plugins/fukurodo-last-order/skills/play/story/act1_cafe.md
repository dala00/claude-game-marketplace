# 第一幕（3）— ふくろう堂

## ナレーション（そのまま提示する）

預かった鍵でガラス戸を開けると、冷めたコーヒーの匂いが薄く残っていた。

細長い店だ。手前にカウンターが六席、奥にテーブルが三つ。壁一面の本棚に、文庫本がぎっしり詰まっている。カウンターの奥が小さな台所、そのさらに奥に——急な木の階段が、二階の住まいへ伸びていた。

階段の下の土間に、うっすらと白いテープの跡が残っている。
九日前の朝、糸井正はここに倒れていた。

店内を見ているうちに、ガラス戸が鳴った。
「——ああ、びっくりした。美咲ちゃんかと思った」

首にタオルを掛けた、日に焼けた男が立っていた。口の中で、カラ、と飴が鳴る。
「とがわ青果の戸川です。商店街の組合で、会長をやらしてもらってる」

戸川茂（とがわ しげる）、六十三歳。糸井とは四十年来の付き合いで、「店は同じ並びの二軒先、組合じゃ俺が会長であいつが会計係」だったという。美咲に店の片付けと組合の手続きの相談があって、顔を出したらしい。

「探偵さん？ ……そうか。美咲ちゃん、納得いっとらんのか」
戸川はタオルで首をぬぐい、土間のテープ跡から目をそらした。
「四十年、隣で商売してきた仲だ。聞きたいことがあったら、何でも聞いてくれ」

## シーン内の自由行動（遷移なし — この範囲で応答する）

- **店内を軽く見る** → 描写してよい範囲: カウンター、本棚、奥の急な階段（しっかりした木の手すり付き）、土間のテープ跡、レジ、メニュー黒板（「本日のコーヒー」の字が残ったまま）。**本格的な現場検証はまだ始めない**。細かく調べようとしたら「腰を据えて調べるなら、まず関係者の顔を覚えてからだ」と沢渡に思わせて自然に流してよい（捜査パートで areas/cafe.md を使う）
- **戸川と話す** → 気さくに答える。「糸井とは中学から一緒よ」「組合じゃ、俺が会長であいつが会計。きっちりした男でな、一円合わんでも夜なべして探すやつ」「再開発の件じゃ、まあ……意見は分かれとったが、それとこれとは別の話よ」。当夜のことを聞かれたら「その晩は、二十二時からやぶ平で組合の寄り合いだった」とだけ（詳細は捜査パートの people/togawa.md で扱う）
- **二階に上がろうとする** → 美咲の立ち会いがあるときに、と沢渡が判断して思いとどまる（捜査パートで areas/upstairs.md を使う）
