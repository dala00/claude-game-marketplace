# 第三幕 — 推理（解決編）

## 開始条件の確認（AI 用）

コア証拠【タイマー】【予約投稿】【検案】【通話】【写し】が揃っているはず。揃っていないのにここへ来てしまった場合は、沢渡自身に「——いや、まだ筋が通らない」と思いとどまらせてハブへ戻る。

## 演出（ナレーション例 — 本文の雰囲気でアレンジ可）

夜、ふくろう堂。
美咲が頼んで回り、関係者が集まった。カウンターに美咲と悠斗。テーブル席に戸川、三好、柏木。店の灯りが、九日ぶりに点いている。

沢渡は手帳を開いた。
「お集まりいただいたのは、糸井正さんが亡くなった夜のことを、最初から並べ直すためです」

（プレイヤーが望めば、ここで獲得済みの手がかりを沢渡が一覧で振り返ってよい）

## 推理の問い（最重要 — プレイヤー自身に説明させる）

以下を**順番に、一つずつ**プレイヤーに問う。まとめて聞かない。プレイヤーが自分の言葉で答えるのを待つ。

1. **「糸井さんが死んだのは、何時だと思いますか。——なぜ、そう言えますか」**
   沢渡自身の問いかけとして場に置く。警察の「二十二時半ごろ」と違う時刻を主張するなら、その根拠（なぜ二十二時半に見えたのか）まで説明させる
2. **「やったのは、誰ですか」**
   名指しを待つ。場が静まり、名指しされた当人が「……根拠を、聞かせてもらおうか」と返す
3. **「決め手は、何ですか」**
   その人物と犯行を結びつける物・記録・矛盾を、プレイヤー自身に挙げさせる
4. **「——なぜ、だと思いますか」**
   動機。プレイヤーが答えられなければ、沢渡が「動機は、ご本人に伺いましょう」と引き取ってよい（**動機の説明は必須としない**）

## 答え合わせ

**ここで初めて `story/truth.md` を Read し、その判定基準に従って答え合わせをする。**

- **死亡時刻のからくりと犯人が正しく、決め手も骨子を突いている** → `story/act4_confession.md` を Read して提示
- **犯人は正しいが、死亡時刻のからくり／決め手が説明できない・大きく誤っている** → 名指しされた当人は静かに否認する。「それじゃ、警察は動かんよ」と三好がつぶやく。ヒントを**一度だけ**——美咲がぽつりと言う。「……父が生きてた『証拠』って、ぜんぶ、人の目じゃないんですね」。それでも組み立てられなければ、「……仕切り直しましょう」と場を解き、ハブ（`act2_hub.md`）へ戻る（証拠は保持。再挑戦は何度でも可）
- **犯人が誤り** → 名指しされた当人の反証（`truth.md` の「誤指名への反証」に従う）を提示し、ハブへ戻る。回数制限はないが、誤指名は場の空気を確実に重くする（美咲の表情が曇る等）

## 注意（AI 厳守）

- `truth.md` を読むのは、プレイヤーが説明を終えてから（上記「答え合わせ」の手順に入ってから）
- 判定は寛容に。言い回しが拙くても、骨子を突いていれば正解として扱う（基準は `truth.md` に明記）
- プレイヤーの推理を進行役が先回りして補完しない。足りなければ登場人物の口で「説明になっていない」と返す
- 問い 1〜4 の途中で、進行役から答えやヒントを差し込まない
