# 第一幕 開幕 — 台風の夕食会

## ナレーション（そのまま提示する）

窓ガラスが、さっきから低く唸っている。

東京、染井川沿いの古い雑居ビル。六階建てを丸ごとリノベーションしたクリエイター向けシェアハウス——**6BASE（ロクベース）**。一階がラウンジとキッチン、二階に配信スタジオと防音室、三階から上が個室。住人は全員、何かしらを「発信」して暮らしている。

透川悠（とおかわ ゆう）。それが、この物語の主人公——プレイヤーの名だ。
二十五歳、フリーランスのゲームデバッガー。バグを、つまり「仕様と挙動の食い違い」を見つけるのが仕事。SNS の入居者募集を見て応募し、一週間のお試し入居の三日目になる。

その三日目に、観測史上最大級と報じられる台風が直撃した。

夜九時、ラウンジ。「どうせ誰も出かけられないっしょ」というオーナーの一声で、夕食会になった。鍋を囲むのは七人。

- **ハジメ**——九条創（くじょう はじめ）、二十九歳。このビルのオーナーで、登録者九十四万人の配信者。配信プラットフォーム「ストリームポート」、通称ストポの看板的存在だ
- **ダイキ**——轟大輝、二十七歳。ハジメの幼馴染で、マネージャー兼ビルの管理人
- **ナギ**——早瀬凪、二十四歳。ハジメチャンネル専属の動画編集者
- **レオン**——蓮見玲音、二十二歳。ゲーム配信者。登録者十一万人
- **ミスミ**——三船美澄、二十三歳。シンガーソングライター。弾き語りをストポで配信している
- **ヒヨリ**——宇佐見日和、二十歳。情報系の大学二年生。機材と回線の面倒を見る代わりに家賃を割り引かれている

ここでは互いをハンドルネームで呼ぶのが流儀で、透川も本名はほとんど知らない。今の並びも、入居書類を預かるダイキがいつか教えてくれたものだ。

「停電あるかもよ、今夜」とヒヨリが言い、「うちのビルは頑丈なんで」とハジメが笑う。
レオンが身を乗り出した。「ハジメさん、コラボの件マジで考えてくださいって」
「いいね。——あ、そうだ」ハジメは鍋から顔を上げた。「来月、でかい発表あるから。チャンネル変わるよ、たぶん」
ナギが箸を置き、水を飲んだ。それだけの間だった。

十時前、ハジメが立ち上がった。
「明日の打ち合わせ資料、やっつけるわ。**スタジオにいるから、二階は朝まで入んないで**。集中したいんで」

風が、また窓を鳴らした。

## シーン内の自由行動（遷移なし — この範囲で応答する）

- **ハジメと話す** → 気さくに応じる。「透川さんだっけ。デバッガーって、バグ見つけて飯食えんの？ いいね、手に職」。お試し入居の感想を聞いてくる。「でかい発表」の中身は「まだ秘密。バズるよ」とはぐらかす
- **ダイキと話す** → 「明日、通販グッズの発送あるんすよ。台風で集荷飛びそうっすけど」と段ボールの山を気にしている
- **ナギと話す** → 短い受け答え。「編集は夜やります。締切あるので」。ハジメの発表について聞いても「私は編集するだけ」
- **レオンと話す** → 早口。「今夜も配信やるんよ。台風の日って意外と人来るんよね」。ハジメへの愚痴を冗談めかして言いかけ、ダイキに睨まれてやめる
- **ミスミと話す** → 「新曲の仮歌、今夜入れちゃいたいんです。……防音室、台風の音も入らないので」と柔らかく笑う
- **ヒヨリと話す** → 「あっ、えっと、川の水位やばいんですよ。ライブカメラ……えっと、川を映してるカメラ、ずっと見てます」と画面を見せてくる
- **台風・建物について聞く** → 染井川の氾濫注意情報が出ている。周辺道路は冠水しはじめている。ビル自体は頑丈
- **二階・スタジオについて行く** → ハジメに「集中したいんで。また明日ね」と軽く断られる
