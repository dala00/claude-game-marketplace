# 配信スタジオ（2F・現場）

## ナレーション（初回訪問時にそのまま提示する）

二階の廊下は、昼間でも薄暗い。階段を上がってすぐの所に、スタジオの防音ドアがある。脇の壁に電子錠のタッチパネル。ドアは今、ヒヨリが開けたときのまま、ストッパーで薄く開いている。

「中、入らないでくださいね。警察に言われてるので……入口から、です」

二十畳ほどの無窓に近い部屋。配信卓、リングライト、防音材の壁、ソファ。その脇の床に、ハジメがうつ伏せに倒れている。誰かが掛けたブランケットの端から、後頭部の暗い色が見えた。

棚の上のトロフィー類の列に、一つぶんの空白がある。そこにあったはずのクリスタルの盾——ストリームポート「クリエイターアワード」が、遺体のそばの床に転がっていた。

## 調査ポイント（このシーン内で完結する応答）

- **遺体を観察する（入口から）** → うつ伏せ。後頭部に裂傷。部屋に争ったような乱れはなく、机の上のコーヒーも倒れていない。ズボンの尻ポケットにスマホ。画面は消えている。触ろうとするとヒヨリかダイキが「現状保存です」と止める。**死亡時刻の推定はできない**（透川は素人。「夜のうちに、としか分からない」）
- **盾を観察する** → クリスタル製で角が重い。血痕。よく見ると、表面に布で拭ったような曇りが筋になって残っている。【証拠獲得: 凶器】
- **机・配信卓** → 印刷された打ち合わせ資料の束。冷め切ったコーヒー。ソファの正面に、スマホ用の三脚が立ったままになっている
- **窓** → 嵌め殺しに近い小さな二重サッシが一つ。施錠されている。外は隣のビルの外壁
- **電子錠を調べる / 出入りの記録を聞く** → ヒヨリが管理アプリを開いて見せる。
  - 仕様: ドアが閉まると自動で施錠（オートロック）。ログは**ドアの開閉そのものの記録**で、中から出るときの解錠も残る。暗証コードは**住人共用**なので、ログから「誰が」開けたかは分からない。**停電中は施錠も解錠もできず、最後の状態のまま固定される**
  - 昨夜の開閉ログ: **21:58 解錠 / 22:20 解錠 / 22:45 解錠**。以後、停電（22:50）から復電（5:10）までは記録なし。次の記録は **6:41 解錠（ヒヨリ）**。今朝、ドアは施錠された状態だった
  - 【証拠獲得: 錠ログ】
- **「朝まで誰も開けてないのか」と確認する** → ヒヨリ「復電が 5:10 で、わたしが開けたのが 6:41。その間にパネルを触ればログが残ります。……残ってません」
